# Icognito — AIOS Dev Squad

Este é um site de apresentação estático para o projeto Icognito.

## Como abrir o site

Para visualizar o site localmente, siga os passos abaixo:

1. Faça o download ou clone este repositório.
2. Localize o arquivo `index.html` na raiz do projeto.
3. Clique duas vezes no arquivo `index.html` para abri-lo no seu navegador de preferência.

## Funcionalidades
- Design responsivo (adaptável a celulares e desktops).
- Alternância de tema (Claro/Escuro) via JavaScript.
- Apresentação dos pilares do projeto: Agentes de IA, Integrações e Execução de Código.
